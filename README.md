# \# JARVIS — Asistente de IA con control por gestos

# 

# Proyecto personal basado en \[H.O.L.O Hands](https://github.com/zubair-trabzada/holo-gestures), ampliado con funciones de asistente inteligente.

# 

# \## 🚀 Descripción

# 

# JARVIS combina una interfaz visual controlada mediante gestos de las manos con un asistente que puede responder preguntas y realizar diferentes tareas desde el ordenador.

# 

# \## ✨ Funciones

# 

# \- 🖐️ \*\*Control por gestos:\*\* interacción con las manos mediante la cámara y MediaPipe.

# \- 🗣️ \*\*Asistente por voz:\*\* respuestas habladas en español.

# \- 🤖 \*\*Inteligencia artificial local:\*\* integración con Ollama y el modelo `qwen2.5-coder:3b`.

# \- 📰 \*\*Noticias:\*\* consulta de noticias mediante Google News RSS.

# \- 📚 \*\*Wikipedia:\*\* búsqueda de información en Wikipedia en español.

# \- 🧠 \*\*Memoria local:\*\* almacenamiento de recuerdos mediante SQLite.

# \- 🕒 \*\*Fecha y hora:\*\* consulta de la fecha y la hora actuales.

# 

# \## 🛠️ Tecnologías

# 

# \- Python

# \- HTML, CSS y JavaScript

# \- MediaPipe

# \- Ollama

# \- SQLite

# \- Git y GitHub

# 

# \## 💻 Instalación

# 

# 1\. Instala Python y Git.

# 2\. Instala \[Ollama](https://ollama.com/) y descarga el modelo:

# 

# &#x20;  ```bash

# &#x20;  ollama pull qwen2.5-coder:3b

# &#x20;  ```

# 

# 3\. Clona este repositorio:

# 

# &#x20;  ```bash

# &#x20;  git clone https://github.com/aodrusqui-spec/prueba-de-jarvis.git

# &#x20;  cd prueba-de-jarvis

# &#x20;  ```

# 

# 4\. Inicia el servidor:

# 

# &#x20;  ```bash

# &#x20;  python server.py

# &#x20;  ```

# 

# 5\. Abre en el navegador la dirección local que indique el servidor. Si mantiene el puerto predeterminado del proyecto, será `http://localhost:4890`.

# 

# \## 🔒 Privacidad

# 

# La base de datos de memoria y las notas locales no deben publicarse
